# Production checklist

- [ ] PostgreSQL создан; доступ ограничен приложением.
- [ ] `.env` хранится только в секретах хостинга.
- [ ] `JWT_SECRET` уникален и длинный.
- [ ] HTTPS включён; `COOKIE_SECURE=true`.
- [ ] `npm run db:init` выполнен.
- [ ] Создан один владелец через CLI; пароль сохранён в менеджере паролей.
- [ ] Проверены роли и разрешения сотрудников.
- [ ] Настроены резервные копии PostgreSQL и файлов.
- [ ] Проверена загрузка/скачивание файлов и лимиты.
- [ ] Проверены login/logout, блокировка аккаунта и права API.
- [ ] Настроены мониторинг, логи и оповещения.
- [ ] Проверены юридические документы, privacy notice и политика хранения данных.
